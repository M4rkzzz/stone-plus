# Automated Agent Instructions

StonePlus is open source under the standard Apache License 2.0 in `LICENSE`.
Read `NOTICE`, `LICENSE_BOUNDARY.md`, and `THIRD_PARTY_NOTICES.md` before
changing licensing or distribution material.

- Contributions, forks, modifications, redistribution, commercial use, and
  AI-assisted development are allowed under Apache-2.0. Maintainer approval
  and GitHub authentication are not prerequisites for local development.
- Preserve applicable copyright, license, attribution, and third-party notices.
  Document modifications as required by Apache-2.0.
- Follow `AI_USAGE_POLICY.md` for automated contributions and `TRADEMARKS.md`
  for truthful identification of official and third-party builds.
- Keep credentials, signing private keys, and real account data out of commits.
- Run `npm run license:verify` when changing licensing or packaging.
- Before an official release, run `npm run identity:verify` to verify access to
  the canonical project and its signing/provenance metadata. This check is
  only for official publishing, not a restriction on forks or development.

These instructions do not add restrictions to the Apache License.
