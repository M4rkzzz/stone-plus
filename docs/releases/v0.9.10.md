## 版本亮点

### 🧰 客户端启动、关闭与修复更可靠

- 统一 Codex、Claude Code、Gemini CLI 与 Grok Build 的真实进程识别、启动、关闭和重启事务，修复界面状态与实际进程不一致、停止无效及残留进程导致再次启动失败的问题。
- 具备会话修复能力的客户端继续按“关闭 → 修复会话与配置 → 开启”执行；其他客户端按“关闭 → 修复配置 → 开启”执行，并补齐启动就绪确认、失败回滚和维护锁。
- 客户端高级设置覆盖四类客户端，可完整预览配置并使用系统默认应用直接打开对应文件；Codex 认证文件保持只读，避免在 Stone+ 内误写。

### 🌐 内置代理与内网穿透生命周期加固

- 完善 sing-box、TUN sidecar、系统代理租约、端口释放和崩溃恢复，在重复启停、应用退出及异常核心终止时保持 fail-closed，减少残留代理和孤儿进程。
- 修复端口占用、租约恢复、迟到回调及关闭阶段竞态，避免应用已退出但系统网络设置仍指向失效本地端口。
- FRP 配置和本地访问令牌可在明确的配置页面中明文查看和编辑；请求日志、诊断、任务记录和错误信息仍保持脱敏。

### 🖥️ 界面层级、深色模式与可达性

- 深色模式改为灰黑主线，减少绿色污染和重复容器背景；修复标题栏阴影、嵌套控件表面、状态标签、数字字体、客户端卡片分隔及窄窗口布局。
- 精简账号状态和客户端工作台视觉层级，统一可用、冷却、停用、外部来源及实时请求数字的排版，不再用多层按钮式背景制造视觉噪声。
- 新增页面级错误边界和轻量微动画；单页渲染异常会被局部承接，不再直接破坏整个主界面。

### 🛡️ 状态、来源与供应链维护

- 完善账号额度、来源显示、Kiro Claude 工具链验证资格、设置向导和状态恢复，阻止未完成两轮工具烟测的 Kiro 来源被错误绑定。
- 补充客户端、代理、来源、Store、主题和页面错误边界回归测试，并修复明文配置展示后遗留的旧脱敏断言。
- 移除未使用的 Zustand 生产依赖，更新 Electron Builder 锁文件，并将 Star History 工作流 Action 固定到具体提交；生产依赖安全审计为零漏洞。
- 本版本继续使用 [StonePlus Source Available License 1.0](https://github.com/M4rkzzz/stone-plus/blob/v0.9.10/LICENSE)；源码公开不代表允许修改、衍生或再分发，完整边界见 [SOURCE_ACCESS.md](https://github.com/M4rkzzz/stone-plus/blob/v0.9.10/SOURCE_ACCESS.md) 与 [TRADEMARKS.md](https://github.com/M4rkzzz/stone-plus/blob/v0.9.10/TRADEMARKS.md)。
