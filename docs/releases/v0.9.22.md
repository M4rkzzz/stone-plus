# Stone+ v0.9.22

## 版本亮点

### 🧠 中转站 Compact 终态兼容

- 修复部分中转站已完成压缩，却仅在最终输出数组中返回压缩项，被误判为缺少压缩结果的问题。
- 同时兼容输出项事件、终态输出和完整 JSON，校验完成后再交给 Codex，保留压缩历史与用量。

### 📡 压缩等待期间保持连接

- 原生压缩等待期间增加轻量 SSE 保活，减少缓冲压缩结果时客户端长时间收不到数据的问题。
- 压缩采用独立的有界等待预算；普通生成的等待策略不变，心跳不会计入模型首字或 Token。

### 🛡️ 续接状态与失败边界

- 原生 Compact V2 请求补齐能力协商，继续走 Responses 路径。
- 保留续接头；响应已绑定上游状态后，不静默换源混用状态。截断、冲突和超时仍明确失败，不伪造成功终态。

## 验证

- 覆盖终态输出、完整历史、缺失和冲突压缩项、延迟压缩、保活、背压、超时释放、故障转移与能力协商回归。
- 完整 ESLint、TypeScript、224 个测试文件、2979 项测试与生产构建通过，2 项按平台跳过；326 项网关、WebSocket 与保活专项回归通过。
- Windows 签名包、打包态 Electron 和随包代理核心烟测通过，页面错误为零；五个平台运行目录及 frpc 固定摘要校验通过。
- 兼容验证使用隔离网关与受控中转响应；未取得用户实际中转站凭据，不声称已验证所有第三方中转实现。

## 下载

- Windows x64 推荐 `StonePlus-0.9.22-windows-x64-setup.exe`；免安装使用 `StonePlus-0.9.22-windows-x64-portable.exe`。
- macOS 提供 Intel / Apple Silicon 的 dmg 与 zip；Linux 提供 x64 / arm64 的 AppImage 与 deb。
- `StonePlus-0.9.22-source.tar.gz` 为本版本完整源码，另附 sing-box 1.13.14 对应源码归档。
- 使用 `SHA256SUMS`、GitHub Artifact Attestation 和 `StonePlus-CodeSigning.cer` 核对完整性与来源。

> Windows 使用项目持续自签名 Authenticode 证书，仍可能出现 SmartScreen 提示；macOS 使用 ad-hoc 签名且未经 Apple 公证。Linux 凭据存储依赖可用的系统密钥环。
