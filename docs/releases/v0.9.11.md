## 版本亮点

### 🌐 订阅规则优先与代理稳定性

- 内置代理不再用 Stone+ 自有规则覆盖订阅内容，优先完整使用订阅自带节点、分组与规则；仅在订阅缺少 Stone+、OpenAI、Claude、Grok 等必要目标时安全补齐代理规则。
- 加固 sing-box 配置生成、节点切换、mixed 端口、系统代理接管和异常退出边界，减少远端用户电脑上启动失败、端口残留及重复启停竞态。
- 继续保持 fail-closed：内置代理已接管后发生核心故障不会静默回退直连，关闭时仍按租约恢复用户原有系统代理设置。

### 🎨 主题编辑器与界面统一

- 设置页新增主题编辑器，内置跟随系统、浅色和深色主题，并可创建、删除自定义主题；提供简易颜色选择器与进阶颜色项。
- 深色模式统一为灰黑主线，提高正文与 OpenAI 等品牌标志对比度，优化状态色、滚动条、标题栏阴影、嵌套控件背景和数字字体。
- 修复账号与中转站编辑窗口、客户端品牌标志、请求记录排版及多个页面的细节可达性问题。

### 📦 安装、来源与账号生命周期

- Windows 安装器在打包前生成 UTF-8 BOM 许可证副本，修复中文许可正文乱码；安装前仍必须明确同意 StonePlus 自定义许可证。
- API 中转地址支持 HTTPS、HTTP、裸 IPv4 和带端口的局域网地址，无协议地址会按 HTTP 安全规范化；OAuth、WebDAV 和更新通道不受影响。
- 删除标准号池中的最后一个账号后保留空号池并停用关联路由，方便用户后续重新补号；不满足聚合条件的聚合中转仍按原规则处理。
