# Stone+ v0.9.27

## 版本亮点

### 🔗 一键连接与切源恢复更可靠

- 修复一键连接未识别 Codex 残留模型配置的问题；显式连接现在使用与实际修复一致的预览和最终校验。
- 切源后的配置校验失败时，同时恢复原路由与配置，清理本次新增的模型目录文件；用户期间的外部修改不会被盲目覆盖。
- 回滚不完整时明确报告并保持 Codex 停止，避免带着异常配置重新启动；完善共享状态目录操作锁及托管 CLI 的环境隔离。

### 🛡️ 减少调度误拦截与连锁故障

- 修复号池中部分账号释放容量后等待请求未及时唤醒的问题。
- Codex 额度保留策略不再误拦截没有 Codex 额度数据的中转/API 等来源；仅剩一个可用来源时，普通流错误和限流不再触发全局冷却，真实凭证失效仍保留保护。
- Web WM 浏览器会话拒绝不再停用普通 Codex 链路共用的 OAuth 账号；并发启动网关合并为同一次启动。
- 兼容 Codex 应用特定无 call_id 的任务引导输出，不为普通工具调用伪造 call_id。

### 🌐 代理规则与应用退出改进

- 自定义规则作为叠加层保留订阅基础策略，正确处理 sing-box 默认出口；新增节点标识使用配置内保存的随机盐。
- 客户端启动前检查网关地址和来源兼容性；更新准备与后台退出增加有界等待，避免单个挂起操作无限阻塞。

### 📖 Apache-2.0 开源与项目文档

- 本版本采用标准 Apache-2.0，允许修改、Fork、再分发、商业使用、托管与 AI 辅助开发；更新英文项目主页并保留中文说明。
- 历史二进制保留随附声明，第三方组件保持原有许可及对应源码交付。详见 [LICENSE](https://github.com/M4rkzzz/stone-plus/blob/v0.9.27/LICENSE)、[SOURCE_ACCESS.md](https://github.com/M4rkzzz/stone-plus/blob/v0.9.27/SOURCE_ACCESS.md) 和 [TRADEMARKS.md](https://github.com/M4rkzzz/stone-plus/blob/v0.9.27/TRADEMARKS.md)。

- 0.9.26 在 Windows 应用烟测中遇到旧提示文案断言，未公开发布。本版更新烟测完成条件，并继续核对切源后的实际路由和配置文件完整性。

## 验证

- 客户端连接修复已补齐真实隔离文件、并发修改保护、取消与失败恢复回归；不操作维护者真实客户端配置。
- 固定 Node.js 22.20.0 / npm 10.9.3 下，ESLint、TypeScript、232 个测试文件（3098 通过、2 跳过）与生产构建通过。
- 五个平台 sing-box 固定摘要与 Windows frpc 校验通过；各平台正式打包、签名和来源证明由官方发布流程阻断验收。
- 本机 Windows 安装包、便携包和主程序的持续签名指纹与时间戳、随包法律资源、代理核心启动退出烟测通过；隔离应用烟测在进入应用前启动失败，正式发布仍要求 GitHub Windows runner 的打包态应用烟测通过。

## 下载

- Windows x64 推荐 `StonePlus-0.9.27-windows-x64-setup.exe`；免安装使用 `StonePlus-0.9.27-windows-x64-portable.exe`。
- macOS 提供 Intel / Apple Silicon 的 dmg 与 zip；Linux 提供 x64 / arm64 的 AppImage 与 deb。
- `StonePlus-0.9.27-source.tar.gz` 为本版本完整源码，另附 sing-box 1.13.14 对应源码归档。
- 使用 `SHA256SUMS`、GitHub Artifact Attestation 和 `StonePlus-CodeSigning.cer` 核对完整性与来源。

> [!WARNING]
> Windows 使用项目持续自签名 Authenticode 证书，仍可能出现 SmartScreen 提示；macOS 使用 ad-hoc 签名且未经 Apple 公证。Linux 凭据存储依赖可用的系统密钥环。

> 连接恢复是有保护的补偿流程，并非跨进程崩溃事务。遇到外部并发修改或回滚失败时会明确提示，不会强行覆盖用户文件或自动启动到未知配置。
>
> 本次锁定依赖的 npm audit 报告仍有 7 项生产依赖告警（4 项 high、3 项 moderate），涉及网络、配置解析及更新依赖；本版未进行额外依赖升级，不声明安全告警已清零。请仅导入可信配置并保持本地管理入口受控。
