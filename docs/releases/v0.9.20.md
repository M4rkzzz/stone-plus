# Stone+ v0.9.20

## 版本亮点

### 🧭 客户端与来源链路隔离

- DeepSeek Harness、WM 路由和 OpenAI Responses 适配使用独立命名空间，主 Codex 链路不受客户端专属流式策略影响。
- 保持工具声明、并行调用、调用 ID、结构化结果、停止原因和会话绑定；无法无损表示的输入继续明确失败。
- ChatGPT OAuth、网页登录、Codex App 配置维护和第三方残留修复统一进入可回滚流程。

### 🧰 配置、额度与长请求稳定性

- 完善 DeepSeek/Grok 工具链、模型族过滤、推理档位、上下文上限、压缩请求和 65 秒健康流终态等待。
- 额度页支持模型专属额度、重置边界和“Stone+ 已释放隐藏额度”估算；定价目录覆盖当前 GPT、DeepSeek、Grok 和 Anthropic 模型。
- 客户端启动、重启、会话修复、账号恢复和设置向导保持进度可见，失败后不覆盖用户新写入内容。

### 🧹 发布与仓库卫生

- 清理旧研究探针、临时解包目录和历史烟测副本，正式 ESLint 只扫描源码、测试和脚本目录。
- 补齐 `@deepseek-ai/dsh-terminal-bash` 的第三方许可证声明，并保留项目许可证、来源材料、签名和 provenance 文件。

## 验证

- `npm run check`：ESLint、TypeScript、223 个测试文件、2935 个测试用例和生产构建全部通过；2 项按平台条件跳过。
- `npm audit --audit-level=moderate`：0 vulnerabilities；`npm ci --dry-run` 可重建依赖树。
- SQLite `quick_check` 与 `integrity_check` 均为 `ok`；FRP 0.69.0、sing-box 1.13.14 五个平台运行目录校验通过。
- Electron 源码态烟测和打包态黑盒启动通过；回环事件服务、诊断日志、客户端生命周期和页面错误检查通过。

## 下载

- Windows x64 推荐下载 `StonePlus-0.9.20-windows-x64-setup.exe`；免安装使用 `StonePlus-0.9.20-windows-x64-portable.exe`。
- macOS 提供 Intel 和 Apple Silicon 的 `.dmg` 与 `.zip`；Linux 提供 x64/arm64 的 AppImage 和 deb。
- `StonePlus-0.9.20-source.tar.gz` 为签名标签对应的完整源码，并附带 sing-box 1.13.14 对应源码材料。
- 使用 `SHA256SUMS`、GitHub Artifact Attestation provenance 和 `StonePlus-CodeSigning.cer` 交叉验证完整性与来源。
