# Stone+ v0.9.23

## 版本亮点

### 🧠 中转站压缩故障自动回退

- 合并 thok404 的 #11：自动压缩遇到部分 Cloudflare 源站 502、非 JSON 网关响应或明确的通用上游失败时，尝试普通 Responses 摘要回退。
- 仅扩展匹配的压缩错误，不把所有 502 一概当成压缩能力缺失；无关上游错误继续明确返回。

### 📦 超大历史与工具兼容

- 压缩回退中的超大文本字段限制为 8 MiB，保留首尾，并明确插入截断标记，减少再次触发上游单字段限制的情况。
- 自动回退使用可移植工具历史、低推理强度和 4096 输出 Token 上限；普通生成请求的内容和参数不变。
- 超限字段的中段会被舍弃，因此该回退不是无损转换，也不保证所有第三方中转站均支持。

### 🤝 双维护者协作

- thok404 纳入授权维护者与关键路径审核名单，发布指南同步支持两名维护者。
- 继续要求签名提交、签名标签、固定发布证书和构建来源验证，不降低发布身份保护。

## 验证

- ESLint、TypeScript、224 个测试文件、2985 项测试与生产构建通过，2 项按平台跳过。
- 新增压缩回退覆盖 Cloudflare JSON、HTML、通用上游错误、无关错误与超大历史；另通过 7 项 UTF-8 与 8 MiB 边界检查。
- Windows 签名包、打包态 Electron 与随包代理核心烟测通过；五个平台运行目录及 frpc 固定摘要校验通过。
- 兼容验证使用隔离网关和受控中转响应，未使用用户实际中转站凭据，不声称修复所有 503 或全部第三方压缩故障。

## 下载

- Windows x64 推荐 `StonePlus-0.9.23-windows-x64-setup.exe`；免安装使用 `StonePlus-0.9.23-windows-x64-portable.exe`。
- macOS 提供 Intel / Apple Silicon 的 dmg 与 zip；Linux 提供 x64 / arm64 的 AppImage 与 deb。
- `StonePlus-0.9.23-source.tar.gz` 为本版本完整源码，另附 sing-box 1.13.14 对应源码归档。
- 使用 `SHA256SUMS`、GitHub Artifact Attestation 和 `StonePlus-CodeSigning.cer` 核对完整性与来源。
