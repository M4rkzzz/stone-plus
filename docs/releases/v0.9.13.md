## 版本亮点

### 🧭 Codex 按模型分流

- Codex 路由现在可以为精确模型选择独立来源。默认请求继续使用主号池，指定模型可切换到另一号池或中转站，并同时应用对应的上游模型映射。
- 模型来源规则会随路由持久化；来源删除、应用重启、旧版设置页保存和模型列表查询都不会留下悬空规则或覆盖默认来源。
- 网关在调度前同时校验来源协议、模型目录和账号策略，未命中的模型仍稳定回到默认号池。

### 🌊 DeepSeek 原生 Responses

- 官方 DeepSeek API 与 DeepSeek-compatible 中转均可作为 Codex 的原生 Responses 来源，保持 Bearer 鉴权、流式输出、推理与工具定义直通，不经过 OpenAI Chat 转换。
- DeepSeek 中转保存后可直接绑定，不要求先通过工具烟测。官方来源只展示当前文档已开放给 Codex 的 `deepseek-v4-flash`，中转来源仍允许自定义模型。
- 对 `previous_response_id`、`store: true` 和显式缓存控制等 DeepSeek 无法等价支持的语义实行发网前明确拒绝，避免请求成功但上下文被静默丢弃。

### 🌐 ChatGPT 网页会话与媒体能力

- ChatGPT OAuth 账号新增隔离网页会话入口，优化认证桥接、启动等待、重试和账号状态识别，减少网络时序差异导致的页面一闪而过或误判登录失败。
- 完善 Plus、Team、K12 等网页状态呈现、历史会话与页面控件恢复；图片支持查看和另存本地，Voice 场景补齐麦克风和媒体权限边界。
- 登录失败继续保持账号隔离并显示明确原因，不向 renderer、日志或页面脚本暴露保存的 OAuth 凭据。

### 📊 更可靠的请求监控与计价

- 迷你请求浮窗持久化位置、尺寸、置顶、不透明度和开启状态；修复 Windows 原生右键菜单、无滚动紧凑布局、主题同步及活动/完成状态区分。
- 更新 OpenAI、Codex、Grok 和 Anthropic 模型价格目录，账本按路由后的实际上游模型累计，并安全迁移可证明的旧统计。
- 增加可选的账号冷却禁用能力，放宽健康流的终态等待边界，同时保持失败分类、并发释放和请求日志一致。

### 🛡️ 稳定性与兼容性

- 加固 Windows 客户端进程发现与唤醒、系统代理重载、设置向导自动路由、更新服务和来源编辑流程。
- DeepSeek、模型分流、网页登录、请求浮窗、定价、客户端进程与持久化均增加自动化回归；现有 OpenAI、Grok、Claude、Gemini、Kiro 和代理工作流保持兼容。
