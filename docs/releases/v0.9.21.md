# Stone+ v0.9.21

## 版本亮点

### 🧠 Compact JSON 兼容修复

- 修复原生 Compact V2 收到完整 JSON 压缩结果时，被误判为缺少 `response.completed` 并返回 502 的问题。
- 兼容 `response.compaction` 和已完成的 Responses JSON；自动转换为 Codex 使用的事件流，无需用户调整配置。

### 📡 保留完整压缩与续接信息

- 按实际内容识别 JSON/SSE，兼容错误 Content-Type、UTF-8 BOM 和任意分片。
- 保留压缩后的历史、加密压缩项、用量与续接头；正常 SSE 继续按原终止协议校验。

### 🛡️ 异常响应有界退出

- 截断 JSON、失败状态、缺失或重复压缩项不会转换为成功终止事件。
- 未完成 JSON 受体积和等待上限保护，客户端取消及时释放上游，校验失败保留提交前故障转移能力。

## 验证

- 新增 21 项 Compact JSON 回归，覆盖分片、错误 Content-Type、完整性校验、超时、取消、超大响应及故障转移。
- 本地完整质量门通过：ESLint、TypeScript、223 个测试文件、2956 项测试和生产构建通过，2 项按平台条件跳过。
- 五个平台 sing-box 运行目录与 Windows frpc 固定摘要校验通过；本机 Windows 签名打包、时间戳、随包法律材料与代理核心烟测通过。
- 打包态 Electron 烟测通过，覆盖页面、配置、客户端生命周期、网关和凭据隔离，未出现页面错误。

## 下载

- Windows x64 推荐 `StonePlus-0.9.21-windows-x64-setup.exe`；免安装使用 `StonePlus-0.9.21-windows-x64-portable.exe`。
- macOS 提供 Intel / Apple Silicon 的 dmg 与 zip；Linux 提供 x64 / arm64 的 AppImage 与 deb。
- `StonePlus-0.9.21-source.tar.gz` 为本版本完整源码，另附 sing-box 1.13.14 对应源码归档。
- 使用 `SHA256SUMS`、GitHub Artifact Attestation 和 `StonePlus-CodeSigning.cer` 核对完整性与来源。
