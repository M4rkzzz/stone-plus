# Stone+ v0.9.24

## 版本亮点

### 🔁 中转站冷却设置生效

- 合并 thok404 的 #15：启用“禁用冷却”后，中转站收到 429、额度耗尽信号或 Retry-After，不再被这些信号放入全局冷却。
- 上游返回的 429 等错误仍原样呈现；账号保持可调度，后续请求可以再次尝试该中转站。

### 🧹 已冷却账号即时恢复

- 开启设置时，恢复已因普通故障或中转站额度信号而冷却的账号，并清理中转站旧的通用额度记录。
- 设置切换后立即更新账号状态，无需手动逐个恢复。

### 🛡️ 官方来源维持额度保护

- 官方 OAuth/API 来源的额度耗尽保护仍然生效；真实凭证失效导致的停用不被“禁用冷却”覆盖。
- 上一版的中转站 Compact 回退与普通 Responses 链路保留。

## 验证

- 在 v0.9.23 主线集成 #15 后，ESLint、TypeScript、224 个测试文件、2986 项测试与生产构建通过，2 项按平台跳过。
- 覆盖中转站限流后再次调度、切换设置后恢复旧冷却、清除旧额度状态和官方来源继续冷却的回归。
- 五个平台 sing-box 运行目录与 Windows frpc 固定摘要通过；Windows 签名包、打包态 Electron 及随包代理核心烟测通过。
- 首次测试在隔离环境中因 Windows 系统进程查询受限失败；允许该查询后，完整检查无代码改动地通过。

## 下载

- Windows x64 推荐 `StonePlus-0.9.24-windows-x64-setup.exe`；免安装使用 `StonePlus-0.9.24-windows-x64-portable.exe`。
- macOS 提供 Intel / Apple Silicon 的 dmg 与 zip；Linux 提供 x64 / arm64 的 AppImage 与 deb。
- `StonePlus-0.9.24-source.tar.gz` 为本版本完整源码，另附 sing-box 1.13.14 对应源码归档。
- 使用 `SHA256SUMS`、GitHub Artifact Attestation 和 `StonePlus-CodeSigning.cer` 核对完整性与来源。
